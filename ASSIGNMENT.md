Dear all,

The second assignment is now available. Using the data cleaned in Assignment 1, build a complete pipeline from images to 3D reconstruction and rendering using NeRF or 3DGS. Analyze which steps throughout the pipeline affect the final reconstruction results.

Run your pipeline on 10 different objects and generate a GIF animation for each object to showcase the reconstruction results.

Each group must submit the following two items:

Pipeline documentation: Describe the complete pipeline and its implementation, present your analysis and findings, and include a link to your GitHub repository.

GitHub repository: Include the complete code, all prompts used, point-matching results for all 10 objects, and GIF renderings generated using NeRF or 3DGS.

Please clearly state your group number, group members’ names, and each member’s contributions in the documentation.
